# AI-Tweet-Generator-Agent
AI powered tweet generator using Gemini LLM and Python

An AI-powered Tweet Generator built using Google Gemini API that generates engaging tweets based on topic, tone, and audience.

## Features
- Generate tweets instantly
- Select tweet tone (professional, funny, marketing)
- Choose target audience
- Simple interactive UI using ipywidgets
- Powered by Gemini LLM

## Technologies Used
- Python
- Google Gemini API
- ipywidgets

## How it Works
1. User enters Topic
2. Selects Tone
3. Selects Target Audience
4. AI generates a tweet using Gemini model
